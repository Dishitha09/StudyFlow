## Change map

1. **Phase 1:** repair the reproduced data issues first. Exercise round trips and safety on isolated profiles. Keep JSON shape, IDs and backup files compatible.
2. **Phases 2–4:** document tokens and reusable components before UI edits. Keep existing routing and controllers; check connected workflows and native sizing in both themes.
3. **Phase 5:** repair material indexing and show source provenance; implement structured questions only via configured remote service and explicit consent.
4. **Phase 6:** calculate date-filtered analytics from durable records. Leave legacy task completion dates unknown.
5. **Phases 7–8:** verify integrations with mocks, confirm package startup and UI evidence, and list live and display checks that could not be performed.
